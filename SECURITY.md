# Security & Privacy Policy

Opportunity Radar is designed with a **privacy-first** architecture.

## Privacy Guarantees

1. **Private Profiles & CVs:** Resumes, skills, and personal information are stored locally in your database instance. They are **never** transmitted to job boards, search providers, or third-party web crawlers.
2. **Human Control:** The application will never automatically submit applications, send messages, or perform actions without explicit user approval.
3. **No Secret Keys in Git:** Never commit `.env` files or API credentials to source control.

## Reporting a Vulnerability

If you discover a security vulnerability in Opportunity Radar, please do not create a public issue. Disclose it privately to the maintainers via GitHub's Private Vulnerability Reporting or via email.
